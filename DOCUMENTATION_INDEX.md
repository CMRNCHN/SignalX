## 🎨 Documentation Conventions

### File Naming
- `UPPERCASE.md` - Root-level important docs
- `lowercase.md` - Package/subdirectory docs
- `CamelCase.md` - Not used (prefer UPPERCASE or lowercase)

### Sections
- Use emoji headers (📚 🎯 🔧 etc.)
- H1 for title, H2 for major sections, H3 for subsections
- Include "Last Updated" date at top

### Code Examples
- Use triple backticks with language tags
- Include comments for clarity
- Show complete, working examples

### Links
- Use relative links within repository
- Absolute links for external resources
- Check links regularly
