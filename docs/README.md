# Documentation

This directory contains project documentation organized by topic.

## Files

- `BUILD.md` - Build instructions and production deployment
- `QUICKSTART.md` - Quick start guide for new developers
- `STATUS.md` - Current project status
- `NEXT_STEPS.md` - Planned next steps and roadmap
- `HANDOFF.md` - Handoff documentation for team transitions
- `VISION_ASSESSMENT.md` - Vision and assessment documentation
- `AESTHETICS_TODO.md` - UI/UX aesthetics and design tasks

## Additional Documentation

Package-specific documentation can be found in:
- `packages/*/README.md` - Individual package documentation
- `packages/*/docs/` - Package-specific detailed docs
